# Upstream provenance

The product plan references `nashsu/llm_wiki` v0.6.11 at commit `e8082119649e6a8e1cf85eaf289adcabfdf39d4e` as a behavioral and visual research baseline.

This initial Sites implementation is original code built with the OpenAI Sites starter. It does not copy the upstream Tauri filesystem adapter, application components, icons, branding, or other source files. The interface follows the plan's generic Obsidian-style layout requirements: an icon rail, page tree, Markdown editor/preview, and contextual revision panel.

If upstream source is selectively imported later, record every file, commit, modification, and applicable GPL-3.0 notice here before release. Until that occurs, no upstream code is represented as part of this source tree.
